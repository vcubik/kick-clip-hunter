# Archivo

The dashboard's typeface. One variable file covers every weight (100-900) and width
(62-125 %) the stylesheet uses.

`Archivo-Variable.ttf` is `Archivo[wdth,wght].ttf` from
[google/fonts](https://github.com/google/fonts/tree/95f4904fc8bcf26d3420fe315560c96417c6dec7/ofl/archivo),
unmodified apart from its file name
(SHA-256 `0e094a7d3c7c4c25cf1310c4b30014f1dae9332220b1c2c88f4fa996f0b05053`).
